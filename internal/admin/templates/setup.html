Per client

iOS · macOS

Calendar and Contacts

  1. Settings → Calendar (or Contacts) → Accounts
  2. Add Account → Other
  3. Add CalDAV (or CardDAV) Account
  4. Server: {{.Host}}

Leave the path off. Discovery goes through /.well-known/caldav, which this server answers without asking for credentials first.

Android

DAVx⁵

  1. Add account → Login with URL and user name
  2. Base URL: the server address above
  3. Enter the account's username and password

One login finds both calendars and address books.

Desktop

Thunderbird

  1. Calendar → New Calendar → On the Network → CalDAV
  2. Location: the calendar home below
  3. Address book → New CardDAV Address Book

Thunderbird wants the home set rather than the server root.

Desktop

Evolution, eM Client

  1. Add a CalDAV or CardDAV account
  2. Use a home set address below
  3. Pick a collection from the list it offers

For clients that want a full URL rather than discovering one.
