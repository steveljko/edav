iOS and macOS — Calendar, Contacts
Settings → Calendar (or Contacts) → Accounts → Add Account → Other → Add CalDAV (or CardDAV) Account. Server: {{.Host}}. Discovery goes through /.well-known/caldav, which this server answers without asking for credentials first, so leave the path off.
DAVx⁵ (Android)
Add account → Login with URL and user name. Base URL: {{.BaseURL}}. It finds both calendars and address books from one login.
Thunderbird
Calendar: New Calendar → On the Network → CalDAV, location {{.CalendarHome}}. Address book: New CardDAV Address Book, location {{.AddressBookHome}}.
